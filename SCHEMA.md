# Database schema

Generated by `tools/schema_doc.py` on 2026-10-27 from the production database `ads_l` (MariaDB 10.11.19-MariaDB-0+deb12u1) and the code at `01839d3`. Do not edit it by hand: run the script again after each migration, as README.md describes, and commit it with `schema.sql`.

Everything here is read from the database or the code except the line that says what a row is and the section of the method that defines it, which are kept in `DESCRIPTIONS` in the script. Columns and keys come from `information_schema`. Writers and readers are the functions whose SQL names the table, directly or through a constant or a list of table names (`nightly.FAMILIES`, the archive steps of `sources.py`). Endpoints are found by following calls from each route of `app.py` through `app.py` and `sources.py`. History lists the files of `schema/` that create, alter or grant on the table; tables older than that directory were described only in the hand-written `schema.sql`, whose commit is given. In the column tables, *PK* is the column's position in the primary key.

Every `day` column is the UTC day of the recording the row was computed from; every `month` is `YYYY-MM`. `lat_idx` and `lon_idx` are `floor(lat * n)` and `floor(lon * n)`, with n = 4 for 0.25-degree cells and 1 for 1-degree cells, and -32768 for rows with no place.
